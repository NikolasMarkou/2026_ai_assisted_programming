# Prompt

You are in a project folder with items.py, test_items.py and fix_plan.md. Do these steps
and nothing else.

1. Read fix_plan.md.
2. Take the first unchecked item. One item only, even if another one looks easy.
3. Fix it in items.py. Do not edit the tests. Do not write approval.txt: only a person
   may write it.
4. Run only the test class named on that item. If it fails, stop and say why.
5. When it passes, tick the item in fix_plan.md and commit items.py and fix_plan.md.
6. Stop. The next pass starts with a new context window.

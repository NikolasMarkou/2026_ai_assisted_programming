# Project: tasklist

## Stack
- Python 3.10 or newer, standard library only. Do not add dependencies.

## Commands
- Test: `python3 -m unittest -q`
- Lint this file: `python3 lint_agents_md.py AGENTS.md`
- Folders: code in `.`, tests in `tests/`.

## Rules
- Write or update a test before changing behavior.
- Run the tests after every change. Do not report done while a test fails.
- Keep tasks.json files written by older versions loadable.

## Done means
- All tests pass, the lint of this file is clean, and the diff has no unrelated changes.
